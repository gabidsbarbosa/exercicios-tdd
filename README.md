# ✅ Exercícios de TDD com TypeScript e Jest

Entrega de 3 exercícios resolvidos com TypeScript e Jest, organizados em:

- **exercicio-1**: Classificação de triângulos.
- **exercicio-2**: Validação de dados de pessoa e e-mail.
- **exercicio-3**: Cálculo de salário líquido por cargo.

## 🚀 Como rodar os testes

1. Instale as dependências:

```
npm install
```

2. Execute todos os testes:

```
npm run test
```

Cada pasta possui seus arquivos *.ts com a lógica e *.test.ts com os testes.
